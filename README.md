### 1️⃣ What is a Nested Loop?
A nested loop means:
> A loop inside another loop.

- **Outer loop** → controls rows  
- **Inner loop** → controls columns / elements in each row

# Day 8:  Brute Force Examples

This folder contains 5 Python examples to practice **brute-force techniques**:

1. **Two Sum (Simple)** — Find two numbers summing to a target
2. **Two Sum (With Negative Numbers)** — Handle negative numbers
3. **Multiple Pairs** — Print all pairs with a specific sum
4. **Skip Odd Numbers** — Sum only even numbers using `continue`
5. **Largest Pair Sum** — Find the pair with the largest sum

All examples use **nested loops** and **basic Python constructs** for better understanding of **brute-force logic**.

💡 Tip: Dry-run each example to see how **indexes and values iterate**.
